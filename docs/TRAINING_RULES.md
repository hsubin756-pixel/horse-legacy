# P1-04 훈련과 휴식

말을 선택하고 휴식·단거리·지구력·언덕·정신 훈련을 배정한다. 배정만으로 시간이 흐르거나 능력이 오르지 않는다. 다음 주간 진행에서 한 번 수행한 뒤 배정을 비운다. 4주 진행은 첫 주 훈련, 이후 3주 휴식이다. 미배정 말은 휴식하며 말마다 배정이 독립적이다.

반복 여부 질문에 대한 답변 전에는 위의 1회 배정을 추천 기본값으로 사용한다. 수치와 성마·은퇴마의 훈련 제한은 Phase 1 개발용 규칙이며 최종 밸런스 확정은 아니다. `data/rules/training_rules.json`에서 조정한다. 훈련비·시설·직원·성격 효과는 이번 범위에 추가하지 않았다.

| 메뉴 | 피로·스트레스가 0일 때 추가 성장 |
| --- | --- |
| 단거리 | 스피드 +0.6, 가속력 +0.5 |
| 지구력 | 지구력 +0.9 |
| 언덕 | 파워 +0.9 |
| 정신 | 투지 +0.5, 지능 +0.6 |
| 휴식 | 컨디션 +5, 피로 -12, 스트레스 -8, 부상 기간 -1주 |

훈련 추가 성장은 `max(0.1, 1 - 피로 × 0.006 - 스트레스 × 0.004)`를 곱한다. 자연 성장·노화는 기존 주간 규칙을 유지하고, 훈련은 해당 능력에 추가로 적용한다. 성장기 이후에도 훈련 효과는 있지만 잠재력을 넘지 않는다. 자연 성장과 훈련 모두 잠재력 자체를 바꾸지 않는다.

훈련은 피로 +22, 스트레스 +10, 컨디션 +2를 적용한다. 시작 피로가 60 이상이면 컨디션은 대신 8 감소한다. 시작 피로 60 미만에서는 훈련 부상이 없고, 60 이상에서는 `0.5 × (피로 - 60 + 1) / 41` 확률로 2주 부상이 발생한다. 현재 기본값의 최대 위험은 50%다. 훈련한 주에는 휴식 회복을 동시에 받지 않는다. 수치는 모두 0~100, 현재 능력은 각 잠재력 이내로 제한한다.

부상 중·자마·은퇴마·사망 기록에는 훈련을 배정할 수 없다. 배정 후 상태가 바뀌어 실행 시 훈련할 수 없으면 휴식으로 전환하고 이유를 보고한다. 사망 기록은 갱신하지 않는다. 부상이 발생한 주에는 부상 기간을 줄이지 않으며, 이후 두 번의 휴식으로 회복한다.

주간 처리는 복제 상태에서 수행한다. 훈련 규칙 파일이 누락되거나 잘못되면 날짜·배정·난수·능력은 바뀌지 않는다. 부상 판정은 저장되는 게임 난수를 사용하고 말 ID 순서로 처리하므로 저장/로드나 말 배열 순서가 결과를 바꾸지 않는다. 4주 진행과 배정을 추가하지 않은 1주 진행 네 번은 동일하다.

배정은 저장 형식 2의 `training_assignments`에 보유 말 ID → 훈련 ID로 저장한다. 휴식은 배정 없음으로 표현한다. 기존 형식 1은 빈 배정으로 불러오며 읽는 도중 원본 파일을 바꾸지 않는다. 화면의 변화 보고서는 최근 진행 결과이며 저장하지 않는다.
