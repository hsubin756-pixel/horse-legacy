# P1-05 기본 경주

선택한 말로 **새벽들 로컬 컵**에 출전한다. 1,600m, 플레이어 말 1두와 기본 경쟁마 3두가 참가한다. 경쟁마는 JSON에 있는 개발용 참가 스냅샷이며 아직 AI 목장이나 혈통 개체가 아니다. 거리·상금·경쟁마 능력·경주 피로는 `data/rules/local_race.json`에서 조정한다. 모두 초기 밸런스 값이다.

## 출전과 시간

3세 이상 성마이며 은퇴하지 않았고 부상 중이 아닌 보유 말만 출전한다. 피로가 높아도 출전은 가능하지만 실제 속도에 불이익이 있다. 출전 확인창에서 대상 말·거리·상금·한 주 소모·훈련 대체를 안내한다. 취소 시 아무 상태도 바뀌지 않는다.

경주는 출전 전 능력·컨디션으로 계산한다. 한 주의 자연 성장·노화는 기존 규칙대로 처리하며, 출전마는 그 주 훈련·휴식 회복 대신 경주를 수행한다. 배정했던 훈련은 취소된다. 다른 말은 배정한 훈련이나 미배정 휴식을 수행한다. 날짜·난수·경주 기록·경력·상금은 임시 상태에서 모두 성공했을 때만 함께 반영한다.

초기 상금은 1~4위 순서로 500 / 200 / 100 / 0이다. 해당 말의 누적 상금과 목장 자금에 같은 금액을 더한다. 참가비·평판·부상 판정·기수·거리/마장 적성·선택 가능한 작전은 이번 경주 범위에 없다. 출전마는 피로 +30, 스트레스 +12, 컨디션 -8을 받는다.

## 계산과 재현성

`RaceSimulator`는 UI 노드·실제 시간과 독립적이다. 0.25초 고정 간격으로 각 말의 속도·위치·스태미나를 갱신한다. 각 말의 진행률에 따라 START(0~3%) → EARLY(~25%) → MIDDLE(~65%) → FINAL TURN(~80%) → FINAL STRAIGHT → FINISH로 전환한다.

- 기본 목표 속도: `12 + Speed × 0.085` m/s.
- 컨디션 계수: `clamp(0.7 + Fitness × 0.003 - Fatigue × 0.002 - Stress × 0.001, 0.4, 1)`.
- 가속: `0.8 + Acceleration × 0.025` m/s²로 목표 속도에 접근한다.
- 초기 스태미나: `40 + Stamina × 0.8`. 초당 소비는 `(속도 / 16)² × (1.2 - Intelligence × 0.003)`.
- 최종 코너에서 Power, 마지막 직선에서 Spirit이 목표 속도에 영향을 준다. 스태미나가 고갈되면 목표 속도를 약 65~75%로 줄인다.
- 경주마다 말별 ±1%의 작은 컨디션 변동을 한 번 뽑는다. 참가 게이트 순서로 처리하므로 입력 배열 순서에 영향받지 않는다.

결승선 통과는 마지막 이동 구간에서 시간을 보간한다. 기록은 마이크로초 정수로 정규화하여 착순을 정하고, 동일 마이크로초라면 게이트 순서로 정렬한다. 현재 UI는 초 소수점 두 자리로 표시하므로 근소한 차이가 같은 시간으로 보일 수 있다. 화면 반올림으로 재정렬하지 않는다. 남은 스태미나는 1/1000 단위 정수로 저장한다. 이는 JSON 전후의 미세한 소수 오차로 기록이 달라지는 것을 방지한다.

게임 난수에서 경주 seed를 하나 얻고 별도 경주 난수로 계산한다. seed와 참가 당시 능력·컨디션을 결과에 보존한다. 계산 결과에는 P1-06에서 사용할 시간별 위치·스태미나·구간 프레임도 반환한다. 프레임은 메모리에만 존재하며 저장 파일에 누적하지 않는다. 경주 계산 버전은 현재 1이다.

## 기록과 저장

고유 `race-*` ID, 날짜, 제목, 거리, seed, 계산 버전, 착순과 참가 스냅샷을 보존한다. Horse의 출전 수·승수·누적 상금·결과 ID 목록은 결과와 일치해야 한다. 같은 결과 ID 또는 같은 말의 같은 주 결과를 다시 반영하지 않는다. 상금이 안전한 정수 범위를 넘으면 경주 전체를 취소한다.

저장 스키마 3·시뮬레이션 4를 사용한다. 기존 스키마 1·2는 빈 경주 기록으로 불러오며 훈련 배정은 보존한다. 미래 버전, 누락된 참가마 참조, 중복 기록, 전적 불일치, 잘못된 착순·상금을 거부한다. 현재 결과는 최대 10,000개, 파일은 기존 16 MiB 한도를 유지한다. 장기 플레이 기록 확장은 실제 데이터 규모에 맞춰 후속 작업에서 평가한다.

현재 화면에서는 출전 확인 후 결과표와 갱신된 전적·자금을 보여주고, 저장 후 불러오면 최근 결과를 다시 표시한다. 결과 표시나 로드는 상금을 다시 지급하지 않는다. 움직이는 말·거리·순위 재생과 재생 속도 조절은 P1-06 작업이다.
