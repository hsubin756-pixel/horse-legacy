# P1-03 주간 진행 규칙

현재 수치는 육성과 세대 순환을 연결하기 위한 초기 조정값이다. 최종 밸런스는 아니며 `data/rules/time_rules.json`에서 조정한다. 한 해는 52주다.

| 항목 | 초기 값 |
| --- | --- |
| 자마 → 성마 | 3세 경계 |
| 휴식 | 매주 컨디션 +5, 피로 -12, 스트레스 -8 |
| 부상 회복 | 매주 남은 회복 기간 -1주 |
| 성장 제한 | 그 주 시작 시 부상 중이거나 피로 60 이상이면 자연 성장 없음 |
| 조숙 | 4세 미만 성장 +0.15/주, 5세부터 감소 |
| 보통 | 6세 미만 성장 +0.10/주, 7세부터 감소 |
| 만성 | 8세 미만 성장 +0.075/주, 9세부터 감소 |
| 능력 감소 | 감소 시기에는 각 능력 -0.05/주 |

성장·감소는 6개 현재 능력에 적용한다. 현재 능력은 0~각 잠재력, 컨디션·피로·스트레스는 0~100에서 제한한다. 유전 잠재력은 바꾸지 않는다. 성장 종료부터 감소 시작 전까지는 현재 능력을 유지한다.

처리 순서는 새 주차 → 나이 기준 성장·감소 → 배정 훈련 또는 휴식(부상 기간 감소 포함) → 성마 전환 → 배정 초기화다. 부상이 그 주에 회복되었으면 다음 주부터 성장할 수 있다. 사망 기록은 갱신하지 않고, 살아 있는 비소유 말도 시간 규칙을 적용하며 휴식한다. 자동 은퇴·사망·교배는 구현 범위에 포함하지 않는다.

한 요청은 복제하고 검증한 게임 상태에서 계산한 후 한 번에 적용한다. 중간에 추가 배정하지 않으면 4주 진행과 1주 네 번 진행은 같은 결과를 낸다. 휴식에는 난수를 사용하지 않는다. P1-04부터 과로 훈련의 부상 판정은 저장되는 게임 난수를 사용한다. 보고서는 마지막 요청의 변화만 표시하며 저장 데이터로 중복 보관하지 않는다.

UI는 1주/4주만 제공한다. 내부 API는 테스트·이후 일정 기능을 위해 1~52주를 허용한다. 4주 진행은 확인을 받고, 주간 요청 중 재진입과 이전 주차의 중복 요청을 거부한다. 버튼에는 0.35초 재입력 방지를 적용한다.

P1-04의 훈련 배정·과로 규칙은 [TRAINING_RULES.md](TRAINING_RULES.md)를 참고한다.
