# P1-06 경주 재생

출전 확인 후 전용 화면에서 실제 계산된 거리만큼 말 실루엣이 이동한다. 내 말은 금색과 ‘우리 목장’으로 구분한다. 표시 줄은 참가마 구분용 도식이며 실제 주로 위치를 뜻하지 않는다. 현재 순위·거리·남은 거리·스태미나·구간·선두를 함께 표시한다.

## 조작

- 기본 4배속, 선택 가능한 배속은 1·4·8이다.
- 일시정지/계속 재생으로 움직임을 멈추거나 이어간다.
- 결과 보기는 남은 재생을 건너뛰고 확정된 착순·시간·상금을 표시한다.
- 모든 말이 완주하거나 결과 보기를 누른 뒤 결과 확인 · 목장으로를 누르면 목장으로 돌아간다.
- 경주 화면에서도 저장·불러오기를 사용할 수 있다. 파일 작업을 시작하면 재생을 멈추며 취소나 저장 후 계속 재생으로 이어갈 수 있다.

경주 중에는 목장 화면을 숨겨 다른 출전·훈련·주간 진행을 잘못 누르지 않도록 한다. 고급 카메라·달리기 애니메이션·효과음·작전·중계 확장은 이번 범위가 아니다.

## 계산과 표시 분리

출전 시 RaceSystem이 경주·주차·전적·상금을 이미 원자적으로 반영한다. RacePlayback은 기록과 프레임의 독립 복사본만 읽는다. 배속·일시정지·건너뛰기·화면 갱신은 게임 난수나 전적을 변경하지 않는다.

0.25초 계산 프레임 사이의 거리를 선형 보간한다. 마지막 이동 구간은 저장된 마이크로초 완주 시각을 끝점으로 사용한다. 미완주 말은 현재 거리와 게이트 순서, 완주 말은 기록된 착순으로 정렬한다. 결과만 표시할 때에는 프레임이나 재계산이 필요하지 않다.

## 저장과 복귀

스키마 4의 pending_race_result_id는 확인을 기다리는 최신 경주를 가리킨다. 새 경주 완료 시 기록하고 결과 확인 · 목장으로를 눌렀을 때 비운다.

- 재생 중 또는 결과 화면에서 저장: 불러올 때 결과 화면으로 복귀한다.
- 결과 확인 후 목장에서 저장: 불러올 때 목장으로 복귀한다.
- 확인 후 다시 저장하지 않았다면 이전 저장의 확인 상태가 유지된다.
- 기존 스키마 1~3: 확인 대기 ID를 빈 값으로 복원하므로 기존처럼 목장에서 이어진다. 기존 훈련·전적·상금·경주 기록은 유지한다.

재생 시각·배속·프레임은 저장하지 않으며 로드에서 경주를 재계산하지 않는다. 시뮬레이션 버전 4, 경주 계산 버전 1은 유지한다. 결과 확인은 복귀 위치만 바꾸며 착순·상금·주차에는 영향을 주지 않는다.
